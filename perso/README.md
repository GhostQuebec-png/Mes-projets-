# Personnel

Espace dédié à ma vie privée, mes décisions personnelles et mes réflexions.

## Périmètre

Tout ce qui n'est ni McDo ni L'Investisseur Ordinaire :
- Vie privée, famille, relations
- Décisions structurantes (logement, carrière, projets personnels)
- Messages sensibles à rédiger ou à analyser
- Finances personnelles
- Réflexions, idées, à creuser
- Santé, sport, équilibre de vie

## Structure du dossier

- `objectifs.md` — Objectifs court / moyen / long terme
- `decisions-importantes/` — Documentation des choix structurants
- `messages-archives/` — Drafts importants, échanges sensibles
- `finances-personnelles/` — Budget perso, projets investissement
- `notes/` — Réflexions libres, idées en germe

## Localisation

- Région : Laurentides, Québec
- Langue de travail : français

## Règles transversales

- Confidentialité maximale : rien de ce qui est ici ne doit fuir dans les autres projets
- Ton humain, direct, sans habillage corporate
- Quand un sujet est émotionnel, prendre du recul avant de rédiger
- Sur les décisions importantes : demander la recommandation explicite avant de trancher
- Distinguer court terme, moyen terme et long terme dans les plans d'action
