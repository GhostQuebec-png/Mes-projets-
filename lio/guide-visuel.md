# Guide visuel — L'Investisseur Ordinaire

## Intention visuelle

L'identité visuelle de L'IO doit communiquer : sérieux sans être froid, accessible sans être cheap, premium sans être élitiste. Un Québécois ordinaire doit se reconnaître dans cette marque tout en lui faisant confiance.

---

## Palette de couleurs

| Rôle | Couleur | Code hex | Usage |
|---|---|---|---|
| Couleur principale | Vert forêt | #1B3A2F | Fonds, en-têtes, éléments dominants |
| Couleur accent | Or | #D4A847 | Titres, highlights, éléments clés |
| Neutre clair | Crème | #F5F0E8 | Fonds secondaires, zones de texte |
| Neutre foncé | Charbon | #2C2C2C | Corps de texte, éléments sombres |
| Blanc | Blanc pur | #FFFFFF | Espaces, contraste, clarté |

### Règles d'utilisation des couleurs

- Le vert forêt est la couleur dominante — il ancre la marque
- L'or est utilisé avec parcimonie — il attire l'attention sur ce qui compte
- Ne jamais utiliser le vert et l'or dans des proportions égales — l'un domine, l'autre accentue
- Le crème remplace le blanc pur sur les fonds pour adoucir l'ensemble
- Le charbon remplace le noir pur pour le texte — moins agressif, plus lisible

---

## Typographie

| Usage | Police | Style |
|---|---|---|
| Logo / Titre principal | Playfair Display | Bold ou Regular |
| Titres secondaires | Playfair Display | Regular |
| Corps de texte | Lato ou Montserrat | Regular |
| Accroches / Citations | Playfair Display | Italic |
| Données / Chiffres | Montserrat | Bold |

### Règles typographiques

- Playfair Display pour tout ce qui est signature et titre — c'est la police identitaire de L'IO
- Lato ou Montserrat pour le corps de texte — lisible, moderne, neutre
- Jamais plus de 2 polices dans un même visuel
- Les chiffres importants en Montserrat Bold — ils doivent être lisibles en un coup d'œil

## Logo

| Élément | Valeur |
|---|---|
| Texte | L'IO |
| Police | Playfair Display |
| Couleur principale | Or #D4A847 sur fond vert forêt #1B3A2F |
| Version alternative | Vert forêt sur fond crème |
| Version monochrome | Blanc sur fond vert forêt |

### Règles d'utilisation du logo

- Toujours utiliser la version fond vert / texte or en priorité
- Ne jamais étirer ou déformer le logo
- Toujours conserver un espace de respiration autour du logo
- Ne jamais placer le logo sur un fond qui crée un manque de contraste

## Éléments visuels récurrents

### Ligne de séparation
- Fine ligne en or #D4A847
- Utilisée pour séparer le contenu du logo ou des sections

### Icône / Badge L'IO
- "L'IO" dans un cercle ou carré arrondi
- Fond vert forêt, texte or
- Taille réduite pour les coins de visuels

### Chiffres mis en valeur
- Grands, en Montserrat Bold
- Couleur or sur fond vert ou vert sur fond crème
- Utilisés pour les statistiques, les montants, les durées

---

## Règles générales de design

- Toujours privilégier l'espace — ne pas surcharger les visuels
- Un visuel = un message principal
- Les chiffres et les faits doivent sauter aux yeux
- Le logo ou le handle @linvestisseurordinaire doit apparaître sur chaque visuel
- Cohérence absolue entre les plateformes — même palette, mêmes polices, même ambiance

---

## Checklist avant publication d'un visuel

- Le fond est en vert forêt, crème ou blanc
- Les titres sont en Playfair Display
- L'accent or est utilisé sur les éléments clés uniquement
- Le handle @linvestisseurordinaire est visible
- Le visuel ne contient pas plus de 2 messages distincts
- Les contrastes sont suffisants pour la lecture sur mobile
- La taille est adaptée à la plateforme cible
